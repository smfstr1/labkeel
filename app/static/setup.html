Set up the dashboard

Create the admin account

This account can control the whole server, so the set-up needs a one-time code from the dashboard's log.

Find it with docker logs <container name> on the server.

At least 12 characters. A few unrelated words make a strong, memorable password.

Other ways to set up

From the server: docker exec -it <container> python accounts.py add <name> --role admin

Or in docker-compose.yml: LABKEEL_ADMIN_USER with LABKEEL_ADMIN_PASSWORD_HASH (made with python accounts.py hash).
