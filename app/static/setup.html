Homelab dashboard

Set a password to finish setting up

The dashboard can restart your containers and your server and read your files, so it stays locked until it has a sign-in.

  1. Add a username and a long password of your own under environment: in the dashboard's docker-compose.yml: 
        environment:
      - DASH_USER=sam
      - DASH_PASS=your-long-password
  2. Apply it from the dashboard's folder: 
    docker compose up -d
  3. Reload this page and sign in.

To run it with no sign-in at all, set DASH_ALLOW_NO_AUTH=1 instead. Anyone who can reach it can then restart the server and read your files, so only do that if nothing else on your network or tailnet can.
