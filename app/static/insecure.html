This connection isn't encrypted

LabKeel only signs people in over HTTPS, so passwords and sessions can't be read on the way. This address reached it over plain HTTP.

  • If you set LABKEEL_HTTPS=off, remove it to let LabKeel use HTTPS itself.
  • Behind a reverse proxy that uses HTTPS, set LABKEEL_TRUSTED_PROXY to the proxy's address, so LabKeel can believe it when the proxy says the visitor used HTTPS.
